СИЛОВОЙ ДНЕВНИК — PWA

Тренировки: выберите A, B или C, затем откройте упражнение.
На экране упражнения видны график и история веса. Нажмите «Начать упражнение»,
введите вес и повторения, при необходимости добавьте подходы.
«Сохранить» записывает подходы в журнал весов, отмечает выполнение и возвращает к списку.
Черновики подходов сохраняются локально. Кнопка «Назад» позволяет вернуться к ним позже.
«Завершить» сохраняет тренировку вместе с подходами в историю и очищает текущие отметки.
Стрелка справа в строке упражнения раскрывает список аналогичных упражнений.
Кнопка добавления сверху списка тренировки и кнопка добавления аналога открывают
одну базу упражнений: группа мышц → упражнение. Экран можно закрыть или вернуться к группам.
Создавать и переименовывать упражнения можно только внутри выбранной группы базы.
Создание в базе не запускает тренировку и не добавляет упражнение в план автоматически.
Выберите сохранённое упражнение, чтобы добавить его в план или в список аналогов.
Добавляйте любое число вариантов из базы и выбирайте исходное упражнение или его аналог.
Нажатие на название открывает выбранный вариант. Его сохранение отмечает выполненным
исходный пункт программы. История веса принадлежит упражнению в базе и доступна из всех
тренировок; текущие подходы каждого варианта и каждой тренировки хранятся отдельно.
Ранее созданные упражнения без связи с журналом автоматически переносятся в базу.

1. Загрузите СОДЕРЖИМОЕ папки gym_pwa на HTTPS-хостинг (например, Netlify Drop: https://app.netlify.com/drop).
2. Откройте полученный HTTPS-адрес именно в Safari на iPhone.
3. Safari → Поделиться → На экран «Домой» → включите «Открывать как веб-приложение» → Добавить.
4. Запустите значок «Тренировки» с рабочего стола. После первого успешного открытия файлы кешируются для работы офлайн.

ВАЖНО:
- ZIP сам по себе нельзя установить как PWA на iPhone, требуется HTTPS-адрес.
- Данные хранятся локально в контейнере установленного веб-приложения. Экспортируйте JSON для резервного копирования.
- Данные из Яндекс Браузера автоматически не перейдут: экспортируйте JSON там и импортируйте в новую PWA.
- Не меняйте домен после установки: локальные данные привязаны к origin приложения.
- Удаление приложения/данных сайта может уничтожить локальную историю.
