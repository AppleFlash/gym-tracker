СИЛОВОЙ ДНЕВНИК — PWA

Три вкладки: Тренировки · Чат · Профиль.
На главной показана следующая тренировка по очереди A → B → C → A.
★ находится в разделе «Дополнительно» и не меняет очередь.
Просмотр программы не начинает занятие: нажмите «Начать» явно.
Одновременно разрешено одно новое занятие. После закрытия приложения оно
и введённые черновики восстанавливаются; несколько занятий старой версии
сначала нужно продолжить, завершить или удалить.

В занятии нажмите «+ Подход», введите вес и повторы, затем «Сохранить».
Предзаполнение само по себе не означает выполненный подход.
«Заменить» открывает основные и альтернативные упражнения: выбор действует
только в этом занятии. Добавленные упражнения и альтернативы остаются в программе.
Подходы разных вариантов сохраняются отдельно, пункт программы остаётся одним.
Нажмите название упражнения для истории, графиков веса/повторов и записи подходов.
Пункт завершается явно; без подходов его можно пропустить.

Вес — как на снаряде; для упражнений с оборудованием «Гантели» — вес одной гантели (объём считается на пару).
Допускаются 0 кг и десятичная запятая. Повторы — целое число от 1.
Объём с отягощением = сумма (вес × повторения) сохранённых подходов.
Старые веса автоматически не пересчитываются; их можно исправить вручную.

«Завершить тренировку» открывает итог. Допускается частичное выполнение,
но нужен хотя бы один подход. Непустые черновики сначала сохраните или отмените.
В итоге подходы можно исправить или удалить; последний подход нового
завершённого занятия удалить нельзя. Изменения отражаются в истории, графиках и ИИ.
Удаление активного занятия доступно через его меню с подтверждением.

В профиле: Прогресс, История, Все упражнения, Настройки.
Каталог открывается сразу списком. Поиск учитывает название и синонимы;
«Все», «Избранное», «В программе» и «Архивные» сочетаются с фильтрами
по группе и оборудованию. Строки показывают последний результат завершённого
занятия и использование в A/B/C/★. Звезда добавляет упражнение в избранное.

В свойствах упражнения можно изменить название, группу, оборудование,
синонимы и личную заметку. ID, прошлые подходы и снимки занятий сохраняются.
Заметка видна рядом с вводом подходов. Из поиска можно создать упражнение:
в режиме выбора оно сразу добавляется в нужный шаблон или альтернативы.
Создание и добавление сохраняются одной операцией. Непустую группу удалить нельзя.
Архивирование сохраняет историю, заметку и технику; использующееся в программе
или активном занятии упражнение сначала нужно освободить от этих связей.

Панель «Альтернативы» предлагает ручной поиск и подбор с ИИ по причине и оборудованию.
Предложения ничего не меняют до «Добавить и выбрать» / «Создать и выбрать».
Новые названия и свойства можно исправить; точные дубли предлагают существующее
упражнение. Рабочий вес исходного упражнения не копируется на замену.

«Техника» открывает отдельную памятку каталожного упражнения. Её можно написать
вручную или запросить у ИИ после уточнения движения и оборудования. Результат
сначала показывается как редактируемый черновик; сохранённая версия доступна
офлайн и меняется только по явному сохранению. Источник, модель и дата видны
рядом с памяткой. Ошибка или отмена генерации не заменяют старый текст.
Памятка может содержать ошибки и не оценивает фактическую технику пользователя.

JSON-схема v3 сохраняет новые свойства; импорт v1/v2 переносит данные без смены ID.
Несохранённые формы каталога защищены подтверждением закрытия, но не обещают
восстановление после перезагрузки. Черновики подходов по-прежнему сохраняются локально.
Графики показывают последние 6 завершённых занятий: максимальный вес,
при равном весе — наибольшие повторы того же подхода. Старый журнал доступен
отдельно в «Ранее сохранённых записях», без выдуманных дат и подходов.
Настройки содержат цель, контекст для ИИ, экспорт и импорт JSON.
Импорт проверяет копию и запрашивает подтверждение замены данных.
Дата экспорта показывает запуск операции, но не гарантирует сохранность файла.

Чат доступен отдельно и через «Разобрать с ИИ» / «Обсудить прогресс».
Контекст и вопрос видны до отправки; запрос отправляется только пользователем.
Ошибка ИИ не влияет на дневник. Тренировки работают без интернета.

1. Загрузите СОДЕРЖИМОЕ папки gym_pwa на HTTPS-хостинг (например, Netlify Drop: https://app.netlify.com/drop).
2. Откройте полученный HTTPS-адрес именно в Safari на iPhone.
3. Safari → Поделиться → На экран «Домой» → включите «Открывать как веб-приложение» → Добавить.
4. Запустите значок «Тренировки» с рабочего стола. После первого успешного открытия файлы кешируются для работы офлайн.

ВАЖНО:
- ZIP сам по себе нельзя установить как PWA на iPhone, требуется HTTPS-адрес.
- Данные хранятся локально в контейнере установленного веб-приложения. Экспортируйте JSON для резервного копирования.
- Данные из Яндекс Браузера автоматически не перейдут: экспортируйте JSON там и импортируйте в новую PWA.
- Не меняйте домен после установки: локальные данные привязаны к origin приложения.
- Удаление приложения/данных сайта может уничтожить локальную историю.


АРХИТЕКТУРА (чистая архитектура, без сборки — нативные ES-модули)
Зависимости направлены только внутрь: ui/adapters → application → domain.
- src/domain/       Сущности и правила: шаблоны и варианты, каталог и старые записи веса,
                    занятия, подходы, статистика, схема данных (валидация и миграции). Без DOM и хранилища.
- src/application/  Use cases (use-cases.js), store с транзакцией «черновик → сохранение → применение»,
                    промпт ИИ-тренера. Порты: repository {load, save}, coach {ask}, clock.
- src/adapters/     Реализации портов: localStorage и прокси Gemini (proxy/api/chat.js).
- src/ui/           Презентеры и контроллеры: экраны, шиты, роутер, жесты, viewport.
                    Читают сущности через чистые функции domain, меняют данные только через use cases.
- src/main.js       Composition root: собирает слои, запускает UI, отдаёт window.gym для диагностики.
- design-system.*   Фреймворк UI (навигация, sheet, alert, графики), не знает о приложении.
- DESIGN_SYSTEM.md  Общие токены отступов, направляющие и правила выравнивания всех компонентов.
Новый файл в src/ нужно добавить в SHELL в sw.js и поднять CACHE_NAME, иначе офлайн его не будет.

ПРОВЕРКИ
По указанию пользователя существующий набор тестов удалён. Новые тесты писать только
для критического функционала и важной бизнес-логики: сохранность данных, миграции,
импорт, атомарное сохранение и ключевые правила занятий. Не покрывать тестами
отступы, классы, вёрстку и простые обратимые действия интерфейса; проверять их в браузере.
Доменный тест можно запускать через node; браузерный сценарий — из консоли страницы
через window.gym. Держать проверки небольшими и привязанными к реальному риску.
Живой Gemini требует доступного прокси и разрешённого origin; подменённый ответ
не подтверждает работу реального сервиса.
Исходный proxy/api/chat.js допускает https://appleflash.github.io и http://localhost:8000.
Для живой локальной проверки ИИ используйте разрешённый origin localhost:8000;
127.0.0.1:8765 и localhost:8765 в этом списке отсутствуют. Прокси в этой задаче не менялся.

УТОЧНЕНИЯ ИНТЕРФЕЙСА
Кнопки «Начать» в списке главного экрана запускают любую тренировку вне очереди.
Второе активное занятие одновременно не создаётся.
Альтернативы можно выбирать только из группы мышц основного упражнения, включая
создание из поиска и принятие ИИ-предложения. Старые связи другой группы сохраняются,
но недоступны для выбора; их можно убрать из программы без удаления прошлых подходов.
В карточке два равных действия: «+ Подход» первым, затем «Альтернативы».
После первого подхода «Завершить» доступно прямо в карточке рядом с «+ Подход».
После планового числа подходов завершение выделено зелёным; одного нажатия достаточно.
При открытом вводе завершение сохраняет корректный подход и остаётся в списке.
Завершённая карточка явно показывает «Завершено» и не реагирует на повторный тап.
Техника, альтернативы начатого упражнения и пропуск доступны через компактное меню «…».
Порядок меняется удержанием и перетаскиванием карточки; с клавиатуры — Alt + стрелки.
На странице упражнения «Сохранить»
и «Завершить» находятся в одной строке, «Завершить» сохраняет корректный черновик
и возвращает к занятию. На узком экране «Отмена» переносится ниже.
Шторка техники не имеет навигационной шапки и занимает высоту по содержимому.
«Закрыть» закреплено самым нижним действием под прокручиваемым текстом и формой.
Блок «О памятке» удалён; ручное сохранение и ИИ-запрос сохранены.
