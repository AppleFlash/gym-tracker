СИЛОВОЙ ДНЕВНИК — PWA

Три вкладки: Тренировки · Чат · Профиль.
На главной показана следующая тренировка по очереди A → B → C → A.
★ находится в разделе «Дополнительно» и не меняет очередь.
Просмотр программы не начинает занятие: нажмите «Начать» явно.
Одновременно разрешено одно новое занятие. После закрытия приложения оно
и введённые черновики восстанавливаются; несколько занятий старой версии
сначала нужно продолжить, завершить или удалить.

В занятии нажмите «+ Подход», введите вес и повторы, затем «Сохранить».
Предзаполнение само по себе не означает выполненный подход.
«Заменить» открывает основные и альтернативные упражнения: выбор действует
только в этом занятии. Добавленные упражнения и альтернативы остаются в программе.
Подходы разных вариантов сохраняются отдельно, пункт программы остаётся одним.
Нажмите название упражнения для истории, графиков веса/повторов и записи подходов.
Пункт завершается явно; без подходов его можно пропустить.

Вес — суммарный внешний: две гантели по 20 кг вводятся как 40 кг.
Допускаются 0 кг и десятичная запятая. Повторы — целое число от 1.
Объём с отягощением = сумма (вес × повторения) сохранённых подходов.
Старые веса автоматически не пересчитываются; их можно исправить вручную.

«Завершить тренировку» открывает итог. Допускается частичное выполнение,
но нужен хотя бы один подход. Непустые черновики сначала сохраните или отмените.
В итоге подходы можно исправить или удалить; последний подход нового
завершённого занятия удалить нельзя. Изменения отражаются в истории, графиках и ИИ.
Удаление активного занятия доступно через его меню с подтверждением.

В профиле: Прогресс, История, Все упражнения, Настройки.
Графики показывают последние 6 завершённых занятий: максимальный вес,
при равном весе — наибольшие повторы того же подхода. Старый журнал доступен
отдельно в «Ранее сохранённых записях», без выдуманных дат и подходов.
Настройки содержат цель, контекст для ИИ, экспорт и импорт JSON.
Импорт проверяет копию и запрашивает подтверждение замены данных.
Дата экспорта показывает запуск операции, но не гарантирует сохранность файла.

Чат доступен отдельно и через «Разобрать с ИИ» / «Обсудить прогресс».
Контекст и вопрос видны до отправки; запрос отправляется только пользователем.
Ошибка ИИ не влияет на дневник. Тренировки работают без интернета.

1. Загрузите СОДЕРЖИМОЕ папки gym_pwa на HTTPS-хостинг (например, Netlify Drop: https://app.netlify.com/drop).
2. Откройте полученный HTTPS-адрес именно в Safari на iPhone.
3. Safari → Поделиться → На экран «Домой» → включите «Открывать как веб-приложение» → Добавить.
4. Запустите значок «Тренировки» с рабочего стола. После первого успешного открытия файлы кешируются для работы офлайн.

ВАЖНО:
- ZIP сам по себе нельзя установить как PWA на iPhone, требуется HTTPS-адрес.
- Данные хранятся локально в контейнере установленного веб-приложения. Экспортируйте JSON для резервного копирования.
- Данные из Яндекс Браузера автоматически не перейдут: экспортируйте JSON там и импортируйте в новую PWA.
- Не меняйте домен после установки: локальные данные привязаны к origin приложения.
- Удаление приложения/данных сайта может уничтожить локальную историю.


АРХИТЕКТУРА (чистая архитектура, без сборки — нативные ES-модули)
Зависимости направлены только внутрь: ui/adapters → application → domain.
- src/domain/       Сущности и правила: шаблоны и варианты, каталог и старые записи веса,
                    занятия, подходы, статистика, схема данных (валидация и миграции). Без DOM и хранилища.
- src/application/  Use cases (use-cases.js), store с транзакцией «черновик → сохранение → применение»,
                    промпт ИИ-тренера. Порты: repository {load, save}, coach {ask}, clock.
- src/adapters/     Реализации портов: localStorage и прокси Gemini (proxy/api/chat.js).
- src/ui/           Презентеры и контроллеры: экраны, шиты, роутер, жесты, viewport.
                    Читают сущности через чистые функции domain, меняют данные только через use cases.
- src/main.js       Composition root: собирает слои, запускает UI, отдаёт window.gym для тестов.
- design-system.*   Фреймворк UI (навигация, sheet, alert, графики), не знает о приложении.
Новый файл в src/ нужно добавить в SHELL в sw.js и поднять CACHE_NAME, иначе офлайн его не будет.
Тесты (tests/*.js) выполняются в консоли открытой страницы и обращаются к приложению через window.gym.
