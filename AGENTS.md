# Правила проекта

## Интерфейс

Перед изменением интерфейса прочитать [DESIGN_SYSTEM.md](DESIGN_SYSTEM.md).
Все экраны и компоненты соблюдают общие токены отступов и вертикальные направляющие.
Внешний горизонтальный отступ задаёт родитель; не добавлять его повторно вложенным
секциям. Проверять целый экран в браузере, включая обе границы содержимого.
Основной viewport для проверки дизайна — Mobile L, ширина 425 CSS px.
У новых и перерабатываемых шторок нет навигационной шапки; «Закрыть» всегда
самая нижняя кнопка в закреплённом footer после прокручиваемого содержимого.
Завершение упражнения доступно одним нажатием из карточки, а не через меню.

## Тесты

Писать тесты только для критического функционала и важной бизнес-логики:
сохранность данных, миграции, импорт, атомарность и ключевые правила занятий.
Для отступов, вёрстки, классов и простых обратимых UI-правок тесты не писать;
проверять их в браузере. Существующий набор тестов удалён по указанию пользователя.

### Проверка результатов

Использовать orca browser и orca cli
